From Dark Souls and Elden Ring font generators to Minecraft sphere/dome/cone builders, Discord symbol makers, and aesthetic text tools – everything runs **100% client‑side** with **no sign‑up, no watermarks, and no server dependencies**.

> 🚀 Try the live tools at **Ghostern** [Gaming Text Tools Platform](https://ghostern.com) – all generators are free and ready to use instantly.

## ✨ Key Features

- **Souls‑Like Fonts** – Create "YOU DIED", boss banners, and gothic overlays with real‑time glow and colour effects.
- **Minecraft Builders** – Generate perfect spheres, domes, and cones with 3D previews, layer‑by‑layer blueprints, and copy‑ready commands.
- **Discord & Symbol Tools** – 200+ symbols, clan tag generator, and aesthetic bio creators.
- **Aesthetic Text** – Vaporwave, pixel art, GTA‑style, and Instagram‑ready fonts with PNG export.
- **Elden Ring Calculator** – AR (Attack Rating) calculator, health bar generator, and class optimisation.
- **100% Client‑Side** – All processing happens in your browser. No data is sent to any server.
- **Zero Friction** – No accounts, no watermarks, no limits.

## 🛠️ Technology Stack

| Technology | Purpose |
|------------|---------|
| HTML5, CSS3, Vanilla JS | Core front‑end |
| Canvas API | 2D rendering & text effects |
| Three.js + OrbitControls | 3D voxel previews (sphere, dome, cone) |
| WebGL | Fallback 3D rendering |
| PHP / WordPress | Content management (not required for tools) |

## 🚀 Quick Start

1. **Clone the repository**  
   ```bash
   git clone https://github.com/sharjeel2025/ghostern-gaming-text-tools.git
   cd ghostern-gaming-text-tools
   ```

2. **Open any tool**  
   Each tool is a standalone HTML file – double‑click `index.html` to open it in your browser.  
   *No server or build process required.*

3. **Customise and extend**  
   Modify the HTML, CSS, or JavaScript directly. All tools use vanilla JS and the Canvas API – no frameworks to learn.
